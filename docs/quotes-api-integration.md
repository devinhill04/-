# Подключение InvestFuture Quotes API 1.2.0

**Ветка:** `feat/quotes-api-v1-calendars`, основана на `integration/calculators-search-and-performance`.

## Что подключено

- `/api/ifq/calendar/bonds` → GET `/api/v1/calendar/bonds` (даты, типы выплат, курсор)
- `/api/ifq/calendar/dividends` → GET `/api/v1/calendar/dividends` (новая вкладка, отсечка и статусы)
- `/api/ifq/calendar/key-rate` → GET `/api/v1/calendar/key-rate`
- `/api/ifq/instruments` → GET `/api/v1/instruments` (справочник акций)
- `/api/ifq/quotes/current` → GET `/api/v1/quotes/current` (цены акций)

Старые `/api/ifq/overview` и `/api/ifq/top40` не изменены. При отсутствии токена календарь облигаций и ключевой ставки остаётся на прежнем HTML-парсере; новая вкладка дивидендов показывает ошибку до настройки токена. Калькулятор дивидендов и цены четвёртого калькулятора используют резервный MOEX при ошибке нового API.

## Секрет и развёртывание

Quotes API требует Bearer-токен. **Не публикуйте секрет в GitHub, Asana, .env.example, Vite-переменных с префиксом `VITE_`, в ссылках или Docker build args.**

- Локально: перед запуском `npm run dev` задайте `QUOTES_API_TOKEN` в переменной окружения терминала (не в коммите).
- Docker Compose: переменная `QUOTES_API_TOKEN` должна присутствовать в *runtime* окружении запуска Compose (либо в приватном `.env` на сервере). `docker-compose.yml` передаёт её только контейнеру nginx.
- Kubernetes: передайте `QUOTES_API_TOKEN` как Secret/переменную окружения runtime.
- **Удалён прежний `--build-arg QUOTES_API_TOKEN`** из GitLab CI. Старые образы, собранные по прежней схеме с токеном, следует считать потенциально содержащими секрет: заменить их и ротировать токен, если он действительно использовался.

Nginx разрешает строго перечисленные пути, кеширует успешные ответы 60 секунд и ограничивает запросы от одного IP. API имеет **общую квоту 60 запросов/мин на токен**, поэтому для высокого трафика нужен мониторинг/общий кэш на сервере; лимит по IP не заменяет глобальный лимит.

## Проверки перед слиянием

```bash
npm ci
npm run lint
npm test
npm run build
npm run dev
```

Проверить в браузере: три вкладки календарей; купон/погашение/амортизацию; подгрузку через `nextCursor`; отсечки и прогнозные статусы дивидендов; работу поиска акций по совпадениям; котировку акции; сценарий **без токена**; ответ сервера 401/429/503; мобильные ширины 320 и 390 px.

### Ограничения

- Котировки могут устаревать; `priceDate` MOEX — московское локальное время без зоны. `observedAtUtc` не делает старую цену новой.
- `null` в датах и суммах календарей означает отсутствие данных и не должен показываться как ноль.
- Календарь облигаций возвращает выплаты, но не готовую формулу доходности облигации; калькулятор облигаций сохраняет прежний источник для формул.
- В Quotes API нет отдельного метода расчёта результата портфеля/XIRR: он остаётся в клиентском модуле.
- Нельзя считать PR протестированным или выпущенным, пока GitLab CI и проверка в браузере не завершены.
