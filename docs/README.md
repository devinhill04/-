# Мини-апп InvestFuture: как устроено и как обслуживать

Регламент для команды: как выпустить версию, обновить данные и найти причину, если что-то сломалось. Ссылки на соседние документы: [прямые ссылки на разделы](deeplinks.md), [туннель до Telegram для новостей](telegram-vpn.md), [точки возврата](../BACKUPS.md).

## Что где

| Раздел приложения | Откуда данные | Где в коде |
| --- | --- | --- |
| «Материалы»: теги и «Готовые решения» | `public/data/posts.json`, карточки в `src/shared/config/figma-data.ts` | `src/pages/home/` |
| «Рынок»: котировки и тепловая карта | API котировок InvestFuture (основной), запасные — ISS Мосбиржи, ЦБ, CoinGecko | `src/entities/quotes/`, `src/entities/moex/` |
| «Рынок»: лидеры роста и падения | все акции Мосбиржи (ISS), как на сайте | `src/entities/moex/model/iss-stocks.ts` |
| «Рынок»: Urals | `public/data/urals-monthly.json`, обновляется вручную раз в месяц | `src/entities/quotes/model/use-quotes.ts` |
| «Рынок»: новости | канал IF News через туннель `telegram-vpn` | `src/entities/news/` |
| «Работа не рабство» (заморожено) | `content/jobs/*.txt` → `public/data/apps/jobs.json` | `src/widgets/catalog-app/` |
| «Календари» (заморожено) | пока разбор страниц сайта, ждём API | `src/entities/calendar/` |

## Выпуск версии

1. Изменения попадают в `main` на GitHub.
2. Из папки проекта: `git pull origin main`, `git fetch gitlab`, `git push gitlab main`. **Никогда не `--force`**: в GitLab бывают чужие коммиты (Серёжа), перезапись их сотрёт.
3. Если GitLab отвечает `rejected (non-fast-forward)` — в GitLab есть новое. Отправить его на GitHub для слияния: `git push origin +refs/remotes/gitlab/main:refs/heads/gitlab-main`, слить с `main`, повторить шаг 2.
4. Пайплайн GitLab: `npm run lint` → `npm test` → `npm run build` → сборка образа. Зелёный пайплайн значит, что образ собран; раскатку в кластер делает инфраструктура (Argo CD).
5. Проверить, что новая версия у пользователей: экран диагностики (ниже) → «Версия» → время сборки позже отправки.

## Переменные и токены

| Переменная | Где задаётся | Зачем |
| --- | --- | --- |
| `QUOTES_API_TOKEN` | GitLab → Settings → CI/CD → Variables (masked) | токен API котировок; nginx подставляет его при старте контейнера, в браузер не попадает. Правильнее — секрет Kubernetes: он перекрывает значение из образа, код менять не нужно |
| `VITE_APP_TITLE`, `VITE_TELEGRAM_BOT_USERNAME`, `VITE_ANALYTICS_WEBHOOK_URL` | GitLab → Variables | передаются в сборку |
| `VITE_COMMIT` | необязательно, `--build-arg VITE_COMMIT=$CI_COMMIT_SHORT_SHA` | номер коммита в экране диагностики |

Локально с данными API: в PowerShell `$env:QUOTES_API_TOKEN = "<токен>"; npm run dev` — сервер разработки подставит токен сам.

## Данные «Рынка»

- **База изменения акций** — закрытие вечерней сессии прошлого дня, как на сайте. Переключается в `src/shared/config/market.ts`.
- **Цифры показываются строками из API как есть**, в формате сайта (`src/shared/lib/exact-format.ts`): без пересчёта и двоичных погрешностей.
- **Кэш**: nginx держит ответы API 30 секунд — на всех пользователей несколько запросов в минуту при лимите API 60.
- **Если API недоступен** — приложение молча переходит на запасные источники, пользователь прочерков не видит; причина видна в экране диагностики.
- **Urals** — раз в месяц, когда Минэкономразвития опубликует среднюю цену за прошлый месяц (обычно в первые дни месяца), обновить `public/data/urals-monthly.json`: `price`, `previousPrice`, `period`, `previousPeriod`, `publishedAt`.

## Контент «Работа не рабство»

Редакция присылает два списка: **карточки** (`content/jobs/categories.txt`) и **теги** (`content/jobs/tags.txt`). Формат: название, затем строки «заголовок - ссылка»; в тегах можно и «Тег<TAB>ссылка». Собрать данные:

```
python3 scripts/txt-to-app-content.py content/jobs/categories.txt content/jobs/tags.txt public/data/apps/jobs.json
node scripts/fetch-tg-titles.mjs public/data/apps/jobs.json   # дописать заголовки постам тегов без подписи
```

Скрипт срезает метки вида `?utm_source=…`, сохраняет значки и цитаты карточек и их внутренние ID при переименовании.

## Заморозка функций

`src/shared/config/features.ts`: читалка постов, второе приложение, календари. При `npm run dev` второе приложение и календари включены, в боевой сборке — выключены, поэтому `main` можно выкладывать в любой момент. Вернуть для всех — поставить `true` и выложить.

## Экран диагностики

**7 нажатий на логотип за 4 секунды.** Показывает версию сборки, устройство, состояние функций, каждый источник данных с причиной ошибки, сверку акций с брокером (цена, время цены, изменение по обеим базам), кнопку «Проверить связь» и «Скопировать отчёт» — его можно переслать разработчику одним сообщением. Личных данных в отчёте нет.

## Аналитика

- Яндекс.Метрика, счётчик 112456720. Цели заводит `node scripts/metrika-setup-goals.mjs` (нужен OAuth-токен с правом записи; сначала `--dry-run`).
- **Параметры каждой цели лежат под её именем**: `tag_click › tag › #Инвестидея`. В виджетах фильтровать по «Параметры визитов, уровень 1» = имя цели.
- Сбои источников у пользователей — цель `market_data_error`, параметр `source`.
- Переходы по прямым ссылкам — цель `deeplink_open`, параметры `route` и `source`; список ссылок — `docs/deeplinks.md` (`node scripts/deeplinks.mjs --app <короткое_имя>`).

## Тесты

`npm test` — автотесты критичной логики (форматирование цифр, разбор API, база процента, лидеры, подписи карты, свежесть данных, теги, календари, диагностика, прямые ссылки). Запускаются в пайплайне до сборки: если тест упал, образ не собирается и сломанное не уходит пользователям.

## Если что-то сломалось

1. Экран диагностики → «Проверить связь» → «Скопировать отчёт» — там видно, какой источник и почему.
2. Новости не грузятся — туннель `telegram-vpn` ([документ](telegram-vpn.md)).
3. Цифры «Рынка» с запасного источника — API или токен (`token_not_configured` в диагностике значит, что токен не дошёл до сервера).
4. Совсем плохо — вернуться к точке из [BACKUPS.md](../BACKUPS.md).
